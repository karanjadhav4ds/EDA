# Statistical Analysis & Visualization (EDA)

## Overview
This project explores retail transaction data through Exploratory Data Analysis (EDA), statistical summaries, visualizations, and statistical testing. It uses Python libraries to investigate distributions, relationships, and patterns in the data.

## Key Features
- Dataset inspection and descriptive statistics
- Missing-value and duplicate analysis
- Histograms and distribution plots
- Boxplots for investigating potential outliers
- Pearson correlation analysis and heatmaps
- Monthly revenue trend analysis
- Country-level transaction comparisons
- Mann–Whitney U test for comparing selected transaction groups
- Summary tables for further analysis

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Jupyter Notebook

## Skills Demonstrated
Exploratory Data Analysis, Statistical Analysis, Data Visualization, Correlation Analysis, Distribution Analysis, Hypothesis Testing, and Data Interpretation.

## Project Purpose
The objective is to understand the structure and behavior of retail data, identify patterns worth investigating, and communicate observations through visual and statistical methods.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Ensure the required dataset is accessible and update its file path if needed.
5. Run the notebook cells in sequence.

**Note:** Statistical findings should be interpreted using the actual notebook outputs. Correlation does not establish causation, and statistical significance does not necessarily imply practical importance.
